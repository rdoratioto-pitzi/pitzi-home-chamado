### GETListar Coletas

https://dash.renovsmart.com.br/api/adm\_logistica/coletas?voucher\_imei=&code=&awb\_code=&rede=&operator=&req\_start=&req\_end=&col\_start=&col\_end=&status=&represados=

AUTHORIZATIONBearer Token

This request is using Bearer Token from collection [API Adm Logística Renov](https://documenter.getpostman.com/view/49982216/2sBXcAJNtS#auth-info-360190eb-e2bc-45fb-9e51-e9dda1aad0cb)

PARAMS

voucher\_imei

Filtro por IMEI, Serial ou Código do Voucher

code

Código da coleta

awb\_code

Código de rastreio (AWB)

rede

Nome da Rede/Filial

operator

Nome do operador logístico

req\_start

Data de início da solicitação (YYYY-MM-DD)

req\_end

Data final da solicitação (YYYY-MM-DD)

col\_start

Data de início da coleta (YYYY-MM-DD)

col\_end

Data final da coleta (YYYY-MM-DD)

status

Status da, ex: 'recebido', 'pendente', 'cancelado'

represados

Filtrar por represados ('não', 'represado' ou 'vencido')

Example Request

Listar Coletas

View More

```curl
curl --location 'https://dash.renovsmart.com.br/api/adm_logistica/coletas?voucher_imei=&code=&awb_code=&rede=&operator=&req_start=&req_end=&col_start=&col_end=&status=&represados='
```
