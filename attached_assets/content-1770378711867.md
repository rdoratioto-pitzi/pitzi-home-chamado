# Admin Logística API

Coleção de endpoints para o painel administrativo de logística.

**Autenticação**: Requer header `Authorization: Bearer Renov123`.

**Base URL**: `https://dash.renovsmart.com.br`

AUTHORIZATIONBearer Token

Token

<token>

### GETColetas

https://dash.renovsmart.com.br/api/adm\_logistica/coletas?voucher\_imei=&code=&awb\_code=&rede=&operator=&req\_start=&req\_end=&col\_start=&col\_end=&status=&represados=

AUTHORIZATIONBearer Token

This request is using Bearer Token from collection [Admin Logística API](https://documenter.getpostman.com/view/49982216/2sBXc8oiGE#auth-info-552c3c5f-208d-4227-9c93-4dce73f12e92)

PARAMS

voucher\_imei

Filtro por IMEI do Vourcher

code

Código da Coleta

awb\_code

Código AWB

rede

Nome da Rede

operator

Operador Logístico (Loggi/Correios)

req\_start

Data de requisição (Início) - YYYY-MM-DD

req\_end

Data de requisição (Fim) - YYYY-MM-DD

col\_start

Data de coleta (Início) - YYYY-MM-DD

col\_end

Data de coleta (Fim) - YYYY-MM-DD

status

Status da Coleta

represados

true/false para filtrar itens represados

Example Request

View More

```curl
curl --location 'https://dash.renovsmart.com.br/api/adm_logistica/coletas?voucher_imei=&code=&awb_code=&rede=&operator=&req_start=&req_end=&col_start=&col_end=&status=&represados='
```
