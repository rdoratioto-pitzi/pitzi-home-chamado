# RenovSmart Integration

Collection para integração do serviço de Scraping de preços.

**Fluxo de Integração:**

- Discovery (/eligible-devices)
- Search/Scraping (/search)
- Analytics (/agg/by-device)
- Internal Price (/eligible-devices/price)
- Ignore Outlier (/result-price/{id}/ignore)

### GET2\. Search (Scraping Engine)

https://rp.renovsmart.com.br/api/search?categoryId=d7f3dcd8-ddf9-4750-b1f8-c20a5bc9d345&manufacturer=APPLE&model=IPHONE 11&storage=64&ignoreLastUpdateDate=false

Realiza o scraping ou busca do cache.

**Atenção:**

- Focar no objeto `raw.shopping_results`.
- O campo `thumbnail` retorna Base64 pesado.
- Usar `extracted_price` (número) para cálculos.

PARAMS

categoryId

d7f3dcd8-ddf9-4750-b1f8-c20a5bc9d345

manufacturer

APPLE

model

IPHONE 11

Deve ser URL Encoded na aplicação (ex: IPHONE+11)

storage

64

ignoreLastUpdateDate

false

Se false: Respeita cache de 7 dias (searchedAt). Se true: Força novo scraping.

### PATCH5\. Ignorar Anúnico (Patch)

https://rp.renovsmart.com.br/api/result-price/:id/ignore

Ignora um preço específico para não afetar as médias.

PATH VARIABLES

id

uuid-do-resultado

UUID do item retornado no endpoint Search

Bodyraw (json)

json

```json
{
    "ignorePrice": true
}
```

Example Request

5\. Ignorar Anúnico (Patch)

```curl

}'
```
