# Renov API Documentation

Documentação Oficial das APIs de Orders e Logística do Dashboard Renov.

## Autenticação

Todas as rotas são protegidas.

O sistema utiliza **Bearer Token**.

**Token Padrão:** Bearer`Renov123`

Este token deve ser enviado no Authorization header de todas as requisições.

## Orders

AUTHORIZATIONBearer Token

### GETBusca Avançada de Pedidos

https://dash.renovsmart.com.br/api/orders/advanced?imei=&voucher\_code=&voucher\_status=&customer\_cpf=&created\_start=&created\_end=&used\_start=&used\_end=&network=&store\_type=&boost=&global\_status=

Retorna uma lista de pedidos com base em múltiplos filtros opcionais. Retorna no máximo 1000 registros.

AUTHORIZATIONBearer Token

This request is using Bearer Token from collection [Renov API Documentation](https://documenter.getpostman.com/view/49982216/2sBXc7Mk6f#auth-info-2356457c-43d3-4e38-88fb-2a6c4485c8b2)

PARAMS

imei

Filtrar por IMEI exato

voucher\_code

Filtrar por código de voucher exato

voucher\_status

Opções: UTILIZADO, DISPONÍVEL, EXPIRADO, NÃO GERADO

customer\_cpf

Filtrar por CPF do cliente (LIKE)

created\_start

Data de criação inicial (YYYY-MM-DD)

created\_end

Data de criação final (YYYY-MM-DD)

used\_start

Data de uso do voucher inicial (YYYY-MM-DD)

used\_end

Data de uso do voucher final (YYYY-MM-DD)

network

Nome da Rede (ex: TIM, CASAS BAHIA)

store\_type

Tipo de Loja: 'Loja Própria' ou 'Dealer'

boost

'true' para apenas com boost, 'false' para sem boost

global\_status

Status Global do pedido (ex: Completed)

Example Request

Busca Avançada de Pedidos

```curl
curl --location 'https://dash.renovsmart.com.br/api/orders/advanced?imei=&voucher_code=&voucher_status=&customer_cpf=&created_start=&created_end=&used_start=&used_end=&network=&store_type=&boost=&global_status='
```
