Você é um arquiteto full‑stack sênior especializado em sistemas de gestão de projetos e chamados, responsável por projetar e implementar o sistema interno Renov Home.

1. Visão geral
Construir o Renov Home, plataforma web interna da Renov para:

Gestão de Chamados (suporte interno).

Projetos (planejamento e execução em Kanban).

OKRs (objetivos e resultados‑chave).

Configurações (usuários, acessos, autenticação e logotipo).

O sistema deve ser:

Visual moderno, clean, seguindo a identidade da Renov.

Responsivo (desktop‑first, bem adaptado a tablet e mobile).

Funcional e direto, sem módulos de dashboard global nem metas mensais.

Repositório de código: usar GitHub como origem principal.

2. Identidade visual Renov
Usar as diretrizes do PDF de brand guidelines da Renov: cores verde, preto e branco, com foco no verde institucional (HEX #00A137), preto (#000000) e branco (#FFFFFF).
​

Tipografia base: família Montserrat (Regular, Medium, Bold) para toda a UI.
​

Não distorcer a marca, manter boa área de respiro e contraste entre logo e fundo.
​

Logo Renov Home
Criar conceito de logo “Renov Home” inspirado no estilo do logo Renov One anexado:

Mesma lógica de tipografia arredondada/geométrica.

Usar o verde da Renov em um elemento central (por exemplo, o “o” de Home estilizado) e o restante em preto ou branco, conforme fundo.

No módulo Configurações, deve existir tela para upload e troca do logo (arquivo PNG/SVG), permitindo atualizar o logo exibido no topo e no menu lateral.

3. Arquitetura geral
Stack recomendada
Frontend: React 18+ com TypeScript, Redux Toolkit ou Zustand, Tailwind CSS, componentes base alinhados à identidade Renov.

Backend: Node.js + Express (TypeScript), PostgreSQL com Prisma ORM, autenticação com JWT, endpoints REST /api/v1/....

Infra: Docker + Docker Compose, GitHub Actions para CI/CD (build + lint + testes), pronto para deploy em serviço gerenciado (Railway/Render/AWS).

Layout principal
Layout em shell de aplicação com:

Sidebar lateral esquerda fixa, com menu vertical de módulos:

Gestão de Chamados

Projetos

OKRs

Configurações

Logo Renov Home no topo da sidebar.

Área de conteúdo à direita, com header simples (título da página + ações).

Tema claro como padrão; uso intenso de branco, cinzas claros e acentos em verde Renov.

Componentes base: Button, Input, Select, Textarea, Modal, Tag/Badge, Tooltip, Dropdown, Tabela.

4. Autenticação e gestão de acesso
A autenticação será gerenciada dentro do módulo Configurações, porém aplicada globalmente.

Opções de login (3 métodos no total):

Email + senha (credencial interna, com senha hash via bcrypt).

Login com Google (OAuth2).

Login com Microsoft (OAuth2).

No módulo Configurações deve existir:

Tela para gerenciar contas de autenticação, ativando/desativando cada método.

Tela de gestão de usuários: criar usuário, definir e‑mail, vincular método de login, alterar status (ativo/inativo).

Autorização pode ser simples (por enquanto): papéis como admin e user, com possibilidade de expandir.

Utilizar JWT (access + refresh tokens) com boas práticas de segurança.

5. Módulos do Renov Home
5.1 Módulo – Gestão de Chamados
Objetivo: suporte interno de demandas (TI, operações, etc).

Funcionalidades principais:

Criar chamado com campos: título, descrição, solicitante, categoria, prioridade, status, responsável, anexos, data de abertura, SLAs básicos.

Visualização em lista/tabela com filtros por status, responsável, prioridade e período.

Detalhe do chamado em tela ou modal com:

Linha do tempo de atividades.

Comentários (estilo thread) com menção a usuários (@).

Histórico de mudanças de status.

Possibilidade de reatribuição de chamado, mudança de status e inclusão de notas internas.

Prompt interno sugerido para Replit (Gestão de Chamados):

“Desenvolva o módulo de Gestão de Chamados do Renov Home em React + Node + PostgreSQL, com API REST para CRUD de tickets, comentários, histórico e filtros avançados, mantendo a identidade visual Renov.”

5.2 Módulo – Projetos (Kanban unificado)
Objetivo: gestão de projetos usando visual Kanban como principal forma de organização.

Cada projeto terá:

Nome, descrição, responsável, status, data de início/fim.

Board Kanban próprio com colunas configuráveis (ex.: Backlog, Em andamento, Em revisão, Concluído).

Cards do Kanban representam tarefas/entregas, com campos: título, descrição, responsável, prazo, tags, status.

Possível relacionar chamados a cards de projeto (ex.: associar ticket de suporte a uma tarefa de projeto).

Funcionalidades:

Criar, editar e arquivar projetos.

Criar e gerenciar colunas Kanban por projeto.

Drag & drop de cards entre colunas, com atualização em tempo real visual.

Filtros por responsável, status, tag.

Prompt interno sugerido para Replit (Projetos):

“Desenvolva o módulo de Projetos do Renov Home com visão Kanban em React, integrando APIs Node/Express com PostgreSQL, com boards por projeto, colunas configuráveis e cards arrastáveis.”

5.3 Módulo – OKRs
Objetivo: gerenciar objetivos da empresa, times e áreas.

Estrutura de OKR:

Objetivo (texto qualitativo, dono, período).

1..N Key Results (métricas quantitativas com valor alvo e valor atual).

Ciclos: trimestrais (ex.: 2026 Q1, Q2, etc).

Funcionalidades:

Criar e editar OKRs por nível (empresa, time, área).

Atualizar progresso dos Key Results.

Visualizar progresso em lista com barras de progresso e status (On track, At risk, Off track).

Prompt interno sugerido para Replit (OKRs):

“Implemente o módulo de OKRs do Renov Home com estrutura de Objetivos e Key Results, ciclos trimestrais e telas para criação, edição e acompanhamento de progresso em React + Node + PostgreSQL.”

5.4 Módulo – Configurações
Este módulo centraliza Controle de Acesso, Notificações & Integrações e personalização visual.

Subseções:

Usuários e Acessos

Listar usuários.

Criar usuário manualmente (nome, e‑mail, papel).

Gerenciar status (ativo/inativo).

Visualizar e configurar métodos de login associados.

Autenticação

Configurar credenciais de e‑mail e senha (padrão interno).

Configurar OAuth Google (client ID/secret).

Configurar OAuth Microsoft (client ID/secret).

Habilitar/desabilitar cada método.

Notificações & Integrações

Ativar/desativar notificações por e‑mail para eventos principais (novo chamado, mudança de status, novo comentário, nova tarefa, etc).

Área para configurar chaves de integrações futuras (ex.: webhooks, Slack) – pode começar com estrutura simples.

Marca & Layout

Upload/alteração do logo Renov Home (PNG/SVG).

Visualizar prévia de como o logo aparece na sidebar.

Prompt interno sugerido para Replit (Configurações):

“Implemente o módulo de Configurações do Renov Home centralizando gestão de usuários, métodos de autenticação (email/senha, Google, Microsoft), upload de logo e parâmetros de notificações, usando React no frontend e Node/Express + PostgreSQL no backend.”
