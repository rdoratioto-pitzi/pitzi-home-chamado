# 🤖 AI Dev System V2

Sistema autônomo para automatizar desenvolvimento.

## ⚡ Quick Start

1. **Criar plan:**
```bash
mkdir -p plans/minha-feature
code plans/minha-feature/plan.md
```

2. **Executar:**
```bash
npm run renov-dev run plans/minha-feature/plan.md
```

3. **Aguardar email** → Testar → Aprovar!
