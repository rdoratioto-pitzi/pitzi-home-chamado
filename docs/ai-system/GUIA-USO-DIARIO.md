# 📖 Guia Rápido de Uso Diário

## 🚀 Workflow em 3 Passos

### 1. Criar Plan (5min)
```markdown
# Título da Feature

## PROMPT 1: Backend
Criar endpoint X que faz Y...
Arquivo: server/routes/...

## PROMPT 2: Frontend
Criar componente Z...
Arquivo: client/src/components/...
```

### 2. Executar
```bash
npm run renov-dev run plans/nome/plan.md
```

### 3. Receber Email → Testar → Aprovar

## 💡 Dicas de Ouro

✅ Ser específico sobre arquivos
✅ Mencionar CLAUDE.md
✅ 1 prompt = 1 coisa
✅ Usar Minimax M2.5 (barato)

❌ Prompts genéricos
❌ Misturar múltiplas features
