# Hello World - Teste AI Dev System

Criar um componente React simples de Hello World para testar o sistema.

## PROMPT 1: Criar Componente

Crie um componente React chamado HelloWorld.tsx em client/src/components/

O componente deve:
- Receber uma prop 'name' (string, opcional, default 'World')
- Renderizar um título H1 com "Hello {name}!"
- Usar Tailwind CSS para estilização (texto verde, centralizado)
- Ser um componente funcional TypeScript

Arquivo principal: client/src/components/HelloWorld.tsx

Use shadcn/ui se necessário.

## PROMPT 2: Adicionar Testes Básicos

Adicione validação básica:
- Se name for vazio, mostrar 'World'
- Componente deve ser exportado como default
- TypeScript strict mode

Arquivo: client/src/components/HelloWorld.tsx (atualizar)
